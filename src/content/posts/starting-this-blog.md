This is a small, quiet corner of the web: short posts, no comments, no algorithm. Just a place to write things down.

## How it is built

The site is built with [Astro](https://astro.build) and plain, modern CSS. Every page is static HTML, so it loads fast and works without JavaScript. Search is the one exception: it runs in the browser with Pagefind.

> Write the thing you would want to read.

Posts are Markdown files. A post can have a title, a cover image and tags, but only a date is required.

```sh
npm run dev
```
